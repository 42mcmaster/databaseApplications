# Data Analytics Drill: Yes/No & True/False Grids

**Course**: Database Applications / Data Analytics (CTE) | **Instructor**: Ryan McMaster — Medina County Career Center  
**Rehearses the DA exam's most common format — judging a row of statements Yes/No or True/False. Each row is graded independently, so partial knowledge shows.**

---

## Part A — Is it QUANTITATIVE data? (Yes = a number/measurement, No = a category)

1. The percentage of teachers teaching more than one subject → `Yes / No`
2. The average number of students at each grade level → `Yes / No`
3. A survey asking teachers their favorite subject → `Yes / No`
4. The eye color of each student → `Yes / No`
5. The number of absences per student → `Yes / No`

## Part B — True or False?

6. In a typical data table, **rows** run horizontally and hold data about a single entity (a record). → `T / F`
7. In a typical data table, **columns** hold a single field/attribute across all records. → `T / F`
8. Data Science typically combines **Computer Science** and **Statistics**. → `T / F`
9. 'Predictions based on measurements from a series of experiments' best describes **data science**. → `T / F`
10. Qualitative data is always numeric. → `T / F`

## Part C — Is this a use of AI in data analytics? (Yes/No)

11. An algorithm predicts customer buying patterns → `Yes / No`
12. A person manually sorts receipts into a shoebox → `Yes / No`
13. A model flags likely-fraudulent transactions automatically → `Yes / No`
14. Summing a column with a spreadsheet SUM formula → `Yes / No`
